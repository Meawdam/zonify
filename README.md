# Zonify — ระบบจองพื้นที่ตลาดนัด

เว็บสำหรับค้นหาตลาดและร้านค้า ดูแผงว่าง จัดการร้านของผู้เช่า จองพื้นที่รายวัน และติดตามการชำระเงิน พร้อมระบบดูแลตลาดสำหรับผู้จัดการและเจ้าของตลาด

ใช้ **Next.js 16, React 19, TypeScript, Express 5 และ MongoDB** โดยหน้าเว็บเรียก API ผ่าน Next.js proxy และตรวจสิทธิ์จากบัญชีที่เข้าสู่ระบบ

## เริ่มตรงไหนดี

- **ผู้ใช้งาน:** อ่านขั้นตอนด้านล่าง ตั้งแต่สมัคร เพิ่มร้าน จองแผง และชำระเงิน
- **ผู้ดูแลตลาด:** ดูหัวข้อ 7 และ [คู่มือผู้จัดการ/เจ้าของตลาด](docs/ADMIN-GUIDE.md)
- **ผู้ติดตั้งระบบ:** ดู [คู่มือติดตั้งและดูแลระบบ](docs/OPERATIONS.md) สำหรับติดตั้ง dependencies ตั้งค่า environment เปิด MongoDB และรัน frontend/backend

> ต้องเปิดระบบก่อนจึงเข้าเว็บ localhost ได้ พรีวิวเป็นข้อมูลทดลองและอาจปิด QR ส่วนระบบรับเงินจริงต้องตั้งค่าบัญชีรับเงินและตรวจสอบก่อนเปิดใช้งาน

คู่มือสำหรับเจ้าของร้านผู้เช่าแผง ผู้จัดการ และเจ้าของตลาด อ้างอิงการทำงานของระบบ ณ วันที่ 18 ตุลาคม 2026

### ปฏิทินตลาดและการแจ้งเตือน

- ผู้ดูแลเปิด `/admin?section=schedule` เลือกตลาด ตั้งวันเปิดประจำสัปดาห์ เพิ่มวันเปิด/ปิดพิเศษ หรือปิดล็อกเป็นช่วงวันพร้อมเหตุผล วันพิเศษมีผลแทนวันประจำสัปดาห์
- หากการปิดกระทบรายการจองปัจจุบัน ระบบจะไม่บันทึกและแสดงรายการให้เปิดตรวจในแท็บใหม่ จัดการจอง/สลิป/คืนเงินตามขั้นตอนก่อนกลับมาลองบันทึกอีกครั้ง แบบร่างยังอยู่ในแท็บเดิม
- เปิด `/admin?section=queue` เพื่อดูจำนวนรอตรวจสลิป รอชำระ และรอคืนเงิน กดแต่ละกล่องเพื่อเปิดรายการพร้อมตัวกรอง
- ผู้เช่ากดกระดิ่ง **แจ้งเตือน** หรือเปิด `/notifications` เพื่อดูผลอนุมัติ ปฏิเสธสลิป ยกเลิกโดยผู้ดูแล และการบันทึกคืนเงิน พร้อมลิงก์กลับรายการจอง ทำเครื่องหมายว่าอ่านแล้วได้ทีละรายการหรือทั้งหมด
- ก่อนหมดเวลาชำระ 5 นาที ระบบแจ้งเตือนเฉพาะรายการที่ยังไม่เคยส่งสลิป หน้าเว็บตรวจข้อความทุก 30 วินาทีขณะเปิดใช้งานและเมื่อกลับเข้าแท็บ ข้อความเตือนชำระที่หมดอายุหรือส่งสลิปแล้วจะไม่แสดง ไม่มีการส่งข้อความออกนอกเว็บไซต์

## 1. เริ่มใช้งาน

เปิดเว็บที่ผู้ดูแลแจ้ง หากรันในเครื่องให้เปิด [http://localhost:3000](http://localhost:3000) โดยต้องเปิดระบบไว้ก่อน ลิงก์ localhost ใช้ได้เฉพาะเครื่องที่รันเว็บอยู่

| ผู้ใช้งาน | หน้าที่ | เมนูหลัก |
| --- | --- | --- |
| ผู้เข้าชม | ค้นหาร้าน ดูตลาดและแผงว่าง | หน้าแรก |
| เจ้าของร้านผู้เช่า (`customer`) | จัดการร้าน จองแผง ส่งสลิป ติดตามรายการของตัวเอง | ร้านของฉัน / รายการจองของฉัน |
| ผู้จัดการตลาด (`manager`) | จัดการข้อมูลตลาด ผังแผง การจอง และตรวจรับเงิน | จัดการตลาด |
| เจ้าของตลาด (`owner`) | สิทธิ์ผู้จัดการ พร้อมรายงานการเงินและสิทธิ์ดูแลบัญชีเพิ่มเติม | จัดการตลาด |

**เจ้าของร้านผู้เช่าใช้บัญชี `customer`** ส่วน `owner` หมายถึงเจ้าของตลาด ผู้สมัครผ่านหน้าเว็บจะไม่ได้รับสิทธิ์ผู้จัดการหรือเจ้าของตลาด

### สมัครและเข้าสู่ระบบ

1. กด **เข้าสู่ระบบ** แล้วเลือก **สมัครสมาชิก** หากยังไม่มีบัญชี
2. กรอกชื่อ อีเมล รหัสผ่าน และยืนยันรหัสผ่าน แล้วสมัคร
3. เข้าสู่ระบบด้วยอีเมลและรหัสผ่านของคุณ
4. ใช้เมนูบัญชีเพื่อเข้าโปรไฟล์ แก้ชื่อหรือเบอร์โทร และเปลี่ยนรหัสผ่าน

เมื่อเปลี่ยนรหัสผ่าน ทุกอุปกรณ์ต้องเข้าสู่ระบบใหม่ หากใช้งานแล้วระบบแจ้งว่าสิ้นสุดการเข้าสู่ระบบ ให้เข้าสู่ระบบอีกครั้ง

## 2. เพิ่มร้านของตัวเอง

1. เปิด **ร้านของฉัน** หรือไปที่ `/merchant`
2. กด **เพิ่มร้านใหม่**
3. เลือกตลาดและประเภทสินค้า แล้วกรอกชื่อร้าน ส่วนรายละเอียด เวลาเปิด เบอร์โทร และ URL ติดต่อให้กรอกตามต้องการ
4. กด **บันทึกข้อมูลร้าน** และรอข้อความยืนยัน
5. หากต้องการรูป ให้เลือก JPEG หรือ PNG ขนาดไม่เกิน **5 MB** แล้วกด **อัปโหลดรูปร้าน** แยกอีกครั้ง
6. กด **ปิดแบบฟอร์ม** เพื่อกลับไปดูรายชื่อร้าน และใช้ **ดูหน้าร้านสาธารณะ** ตรวจข้อมูลที่ผู้เข้าชมเห็น

หนึ่งบัญชีมีหลายร้านได้ แต่ละร้านอยู่ในตลาดเดียวและเปลี่ยนตลาดภายหลังไม่ได้ หากขายอีกตลาดให้เพิ่มร้านใหม่ ข้อมูลติดต่อและรูปภาพที่กรอกจะแสดงสาธารณะ

แก้ร้านเดิมโดยกด **แก้ไขร้าน …** จากการ์ดร้าน แล้วบันทึก หากผู้ดูแลปิดใช้งานร้าน คุณยังแก้ข้อมูลได้ แต่ต้องติดต่อผู้ดูแลเพื่อเปิดใช้งานก่อนใช้ร้านนั้นจองแผงใหม่

## 3. เลือกแผงและจองพื้นที่

1. จากร้านของฉัน กด **เลือกแผงและจองพื้นที่** หรือเปิดผังตลาดบนหน้าแรก
2. เลือกตลาดและวันที่ขาย เลือกได้ตั้งแต่วันนี้ถึงอีก **365 วัน** ตามเวลาไทย
3. เลือกแผงสถานะ **ว่าง** จากผัง หรือสลับเป็น **ดูรายการล็อก** เพื่อกรองสถานะ โซน และราคาสูงสุด
4. ตรวจรหัสแผง ขนาด ราคา และวันที่ กด **ดูรายละเอียดและดำเนินการต่อ** หากกำลังดูสรุปแผง
5. เลือก **จองให้ร้าน** เป็นร้านของคุณในตลาดนั้น หากมีร้านเดียวที่ใช้ได้ ระบบเลือกให้ หากไม่มีให้กด **เพิ่มหรือจัดการร้าน**
6. กด **พักล็อกนี้ 10 นาที** ระบบสงวนแผงไว้ชั่วคราวและเปิดรายละเอียดรายการ
7. ตรวจรายละเอียดอีกครั้ง แล้วกด **ดำเนินการชำระเงิน** ก่อนหมดเวลาพักล็อก เพื่อเข้าสู่ช่วงชำระเงิน **30 นาที**

ราคายึดตามเวลาที่พักล็อก การรีเฟรชหน้าไม่ต่อเวลา หากมีคนอื่นจองได้ก่อน ระบบจะแจ้งให้เลือกแผงอื่น **การพักล็อกและการกดดำเนินการชำระเงินยังไม่ใช่การจองสำเร็จ**

## 4. ชำระเงินและส่งสลิป

1. เปิดรายละเอียดจาก **รายการจองของฉัน** แล้วกด **แสดง QR ชำระเงิน**
2. ตรวจชื่อบัญชีผู้รับและยอดเงินในแอปธนาคารก่อนโอน
3. หลังโอน เลือกภาพสลิป PNG/JPEG ไม่เกิน **5 MB** และกรอกยอด วันและเวลาโอน **ตามเวลาไทย** พร้อมเลขอ้างอิง
4. ส่งหลักฐานภายในเวลาที่เหลือ แล้วตรวจว่าสถานะเปลี่ยนเป็น **รอตรวจสอบสลิป**
5. รอผู้ดูแลตรวจเงินเข้า สถานะ **ยืนยันแล้ว** หมายถึงการจองสำเร็จ

หากสลิปถูกปฏิเสธ ให้เปิดรายการ อ่านเหตุผล และแก้ข้อมูลหรือส่งหลักฐานใหม่ภายใน 30 นาที ระบบจำกัดไม่เกิน 10 ครั้งต่อรายการ **หากโอนเงินแล้วอย่าโอนซ้ำ** ให้แก้หลักฐานหรือติดต่อผู้ดูแล

หากระบบแจ้งว่ายังไม่ได้ตั้งค่ารับชำระเงิน ให้ติดต่อผู้ดูแลก่อนดำเนินการต่อ พรีวิวที่ใช้สาธิตอาจปิดการสร้าง QR และใช้ฐานข้อมูลชั่วคราว

## 5. ดูสถานะ ประวัติ และยกเลิก

| สถานะ | ความหมาย | สิ่งที่ต้องทำ |
| --- | --- | --- |
| พักล็อก | สงวนพื้นที่ชั่วคราว 10 นาที | ตรวจรายละเอียดและเข้าสู่ขั้นชำระเงิน |
| รอชำระเงิน | อยู่ในช่วงชำระเงิน | โอนและส่งหลักฐานก่อนหมดเวลา |
| รอตรวจสอบสลิป | ส่งหลักฐานแล้ว ผู้ดูแลกำลังตรวจ | รอผลหรือติดต่อผู้ดูแล โดยรายการไม่หมดอายุเองระหว่างตรวจ |
| ยืนยันแล้ว | ผู้ดูแลตรวจรับเงินแล้ว | ใช้พื้นที่ตามวันและแผงในรายการ |
| ยกเลิกแล้ว | รายการถูกยกเลิก | ดูเหตุผลและสถานะคืนเงินถ้ามี |
| หมดอายุ | ไม่ดำเนินการทันกำหนด | เลือกและจองพื้นที่ใหม่ |

เปิด **ร้านของฉัน** เพื่อดูรายการที่ต้องดำเนินการ ยอดรอชำระ รายการปัจจุบัน และประวัติ ยอดรอชำระรวมเฉพาะรายการที่เข้าสู่ขั้นชำระเงินแล้ว

ใน **รายการจองของฉัน** กรองร้าน ตลาด วันที่ สถานะ หรือกลุ่มรายการได้ ตัวกรองอยู่ใน URL จึงรีเฟรชหรือใช้ Back/Forward กลับมาได้ รายการยืนยันที่วันเช่าผ่านไปจะอยู่ใน **ประวัติ**

ยกเลิกเองได้เฉพาะช่วงพักล็อกหรือรอชำระ โดยกด **ยกเลิกรายการ** กรอกเหตุผล และยืนยัน รายการรอตรวจสลิปต้องให้ผู้ดูแลตรวจเสร็จก่อน รายการยืนยันแล้วให้ติดต่อผู้ดูแลเรื่องยกเลิกและคืนเงิน ระบบแสดงผลการคืนที่ผู้ดูแลบันทึก แต่ไม่ได้โอนคืนอัตโนมัติ

## 6. ค้นหาร้านและดูตำแหน่ง

บนหน้าแรก ค้นหาด้วยชื่อร้านหรือสินค้า แล้วกรองตลาดและหมวดหมู่ กดชื่อร้านหรือ **ดูร้านค้า** เพื่ออ่านรายละเอียด รูป เวลาเปิด และช่องทางติดต่อ

ตำแหน่งร้านของผู้เช่ามาจากแผงที่ **ยืนยันการจองแล้วในวันที่เลือก** เปลี่ยนวันที่ในหน้าร้านเพื่อดูวันอื่นได้ หากไม่พบตำแหน่งในวันนั้นไม่ได้แปลว่าร้านถูกลบ ร้านเดิมที่ผู้ดูแลกำหนดตำแหน่งจะแสดงข้อความว่ามาจากข้อมูลผู้ดูแล

## 7. ผู้จัดการและเจ้าของตลาด

1. เข้าสู่ระบบด้วยบัญชีที่ผู้ดูแลจัดสิทธิ์ให้ แล้วเปิด **จัดการตลาด** หรือ `/admin`
2. ใช้ส่วนตลาด หมวดหมู่ โซน และ **จัดผังล็อก** เตรียมพื้นที่ ราคา ขนาด และสถานะเปิดใช้งาน
3. เปิด **รายการจอง** เพื่อตรวจร้าน ผู้จอง ตลาด วัน แผง และสถานะ หรือเปิด **พักล็อก** เพื่อคืนแผงที่ยังเป็นการพักชั่วคราว พร้อมระบุเหตุผล
4. เปิด **ตรวจชำระเงิน** หรือ `/admin?section=payments` เพื่อดูรายการรอตรวจและหลักฐานการโอน
5. เทียบภาพสลิปกับยอด ผู้รับ วันเวลา และเงินเข้าในบัญชีจริง หากถูกต้องระบุเลขอ้างอิงที่ตรวจพบและยืนยันการรับเงิน หากไม่ผ่านระบุเหตุผลให้ผู้เช่าแก้ไข
6. หากยกเลิกรายการที่รับเงินแล้ว ให้โอนคืนจริงก่อนกรอกเลขอ้างอิงและกด **บันทึกคืนเงิน**
7. เปิด **Dashboard** หรือ **รายงาน** เลือกช่วงวันและตลาด แล้วแสดงผลก่อนดาวน์โหลด CSV รายงานการเงินเพิ่มเติมใช้สิทธิ์เจ้าของตลาด

การเปลี่ยนราคาใช้กับการพักล็อกใหม่ การจองเดิมเก็บราคาของรายการไว้ การปิดใช้งานเก็บข้อมูลและประวัติไว้ ผู้เช่าไม่สามารถอ้างสิทธิ์ร้านเก่าที่ผู้ดูแลสร้างให้ตัวเองได้

ก่อนรับเงินจริง ผู้ดูแลระบบต้องตั้งค่าบัญชีรับเงินตาม [คู่มือติดตั้งและดูแลระบบ](docs/OPERATIONS.md) และตรวจ QR กับแอปธนาคาร

| ไม่พบร้านในตัวเลือกจอง | ตรวจว่าร้านอยู่ตลาดเดียวกับแผงและเปิดใช้งาน หากยังไม่มีร้านให้เพิ่มก่อน |
| บันทึกข้อมูลร้านไม่สำเร็จ | อ่านข้อความรายช่อง แก้เฉพาะที่ผิด แล้วลองบันทึกอีกครั้ง |
| ร้านถูกแก้จากอีกแท็บหรือผู้ดูแล | กด **โหลดเวอร์ชันล่าสุดและคงข้อมูลที่กรอก** เปรียบเทียบข้อมูล แล้วแก้ฟอร์มก่อนบันทึกอีกครั้ง |
| โหลดข้อมูลเบื้องหลังไม่ได้ | ใช้ปุ่มลองใหม่ แบบฟอร์มและไฟล์ยังอยู่เมื่อเป็นข้อผิดพลาดชั่วคราว หลีกเลี่ยงการปิดหรือรีเฟรชหน้าขณะยังไม่บันทึก |
| มีคำเตือนก่อนออกจากหน้า | บันทึกก่อน หรือยืนยันละทิ้งเมื่อไม่ต้องการข้อมูลที่กรอก |
| ไม่เห็นเมนูจัดการตลาด | ตรวจว่าบัญชีมีสิทธิ์ manager/owner การสมัครเองไม่ได้สิทธิ์นี้ |
| เปิด localhost ไม่ได้ | ให้ผู้ดูแลเปิด frontend/backend ตามคู่มือติดตั้ง และเปิดเว็บจากเครื่องที่รันระบบ |

ใช้งานคีย์บอร์ดได้ด้วย Tab เพื่อย้ายโฟกัสและ Enter เพื่อกดปุ่มหรือส่งแบบฟอร์ม เมื่อข้อมูลไม่ถูกต้อง ให้ตรวจข้อความกำกับช่องที่ระบบโฟกัสให้
