# คู่มือผู้จัดการและเจ้าของ Zonify

ล็อกอินด้วยบทบาท manager/owner แล้วใช้เมนูจัดการตลาดที่ /admin ลูกค้าไม่เห็นสิทธิ์จัดการ API ตรวจบทบาทปัจจุบันจากฐานข้อมูลทุกครั้ง หน้า signup ไม่สร้างบทบาทพิเศษ บัญชีตัวอย่างอ่านรหัสผ่านจาก backend/.env และสร้างผ่าน seed โดยไม่เขียนทับบัญชีเดิม

เปิดลิงก์ `/admin?section=payments` เพื่อเข้าส่วนตรวจชำระเงินโดยตรง ส่วนจัดการและตัวกรองรายการเก็บใน URL จึงใช้ reload และ Back/Forward ได้ ค่า section หรือเลขหน้าที่ไม่ถูกต้องใช้ค่าเริ่มต้น ไม่มีผลเพิ่มสิทธิ์ผู้ใช้

เมื่อแก้แบบฟอร์มแล้วแต่ยังไม่บันทึก การปิดแบบฟอร์ม เปลี่ยนรายการแก้ไข หรือเปลี่ยนส่วนจัดการจะแจ้งยืนยันก่อนละทิ้งข้อมูล หาก Back/Forward เปลี่ยนส่วนขณะมี draft ระบบยังเปิดแบบฟอร์มเดิมไว้จนบันทึกหรือปิด การออกไปหน้าอื่นหรือ reload ใช้คำเตือนของเบราว์เซอร์ด้วย

## ข้อมูลหลักและผัง

สร้างตลาด → หมวดหมู่/โซน → ล็อก → ร้านค้า อ้างอิงร้าน/โซน/ล็อกในตลาดเดียวกัน รหัสล็อกและตำแหน่งแถว/คอลัมน์ต้องไม่ซ้ำ แก้ตำแหน่ง/ขนาด/ราคาได้จากจัดผังล็อก ราคาใหม่ใช้กับการพักล็อกใหม่ การจองเดิมเก็บราคาที่บันทึกแล้ว

ปิดใช้งานเก็บเอกสารและประวัติไว้ เปิดกลับจากแก้ไขได้ ปิดตลาด/ร้าน/หมวดหมู่ทำให้ไม่ปรากฏต่อผู้เข้าชม ปิดโซนทำให้ล็อกในโซนไม่พร้อมจอง หากบันทึกชนกัน (409) โหลดข้อมูลล่าสุดก่อนแก้ต่อ อย่าบันทึกทับข้อมูลเดิมโดยไม่ตรวจ

## จอง พักล็อก และชำระ

กรองรายการจองตามวัน ตลาดและสถานะ ดูข้อมูลติดต่อลูกค้า คืนเฉพาะรายการที่ยังเป็นพักล็อกได้พร้อมเหตุผล รายการรอชำระที่หมดเวลาอัตโนมัติคืนพื้นที่ ส่วน **รอตรวจสลิปไม่หมดอายุเอง** ต้องตรวจหลักฐานก่อนจัดการ

ตรวจชำระเงิน: เปิดภาพส่วนตัว เทียบยอด วันเวลา ผู้รับ และเลขธุรกรรมกับธนาคารจริง หากถูกต้องระบุเลขอ้างอิงที่ตรวจพบ ยืนยันการตรวจแล้วอนุมัติ หากไม่ผ่านใส่เหตุผลให้ลูกค้าแก้หลักฐาน สลิป/เลขอ้างอิงที่รับแล้วใช้ยืนยันรายการอื่นไม่ได้

ยกเลิกรายการที่รับเงินแล้วสร้างภาระรอคืนเงิน หลังโอนคืนเงินจริงจึงบันทึกเลขอ้างอิง ระบบไม่โอนคืนหรือเชื่อมธนาคาร การบันทึกซ้ำด้วยเลขเดิมไม่เพิ่มรายการซ้ำ เก็บหลักฐานและเหตุผลไว้ตรวจย้อนหลัง

ก่อนรับเงินจริง ตั้ง PROMPTPAY_ID/PROMPTPAY_NAME ตามคู่มือติดตั้ง แล้วตรวจ QR กับแอปธนาคารของบัญชีจริง การทดสอบอัตโนมัติใช้บัญชีสมมติและไม่มีการโอนจริง ไม่ใช้ค่าทดสอบรับเงินลูกค้า

## ข่าวและรายงาน

โฆษณาเลือกตลาด ร้าน (ถ้ามี) ชื่อ/ข้อความ ภาพเดิม วันแรก/วันสุดท้าย ลำดับและเปิดแสดง ช่วงวันรวมวันต้น/ท้ายตามเวลาไทย ไม่ใส่ URL ภายนอก ระบบลิงก์ไปข้อมูลภายในเอง ข่าวของร้าน/หมวดหมู่/ตลาดที่ปิดแสดงจะซ่อนจากหน้าแรก

Dashboard แยกสถานะจองออกจากรับ/คืนเงิน เลือกวัน/ตลาดได้ รายงานการจองรวมตามวันที่จอง ค่าเช่าตาม snapshot **ยังไม่ใช่รายรับ** เจ้าของมีรายงานรับ/คืนเงินเพิ่ม โดยอิงวันที่ผู้จัดการบันทึกตรวจรับหรือคืนจริง ยอดสุทธิของวันคืนเงินอาจติดลบ “รอคืนเงินทั้งหมด” คือภาระปัจจุบันทุกวันของตลาดนั้น

เลือกวัน ตลาด รายวัน/เดือน แล้วกดแสดงรายงานก่อนดาวน์โหลด CSV ไฟล์ใช้ตัวกรองของรายงานที่แสดงและไม่มีข้อมูลติดต่อลูกค้า ไม่เกิน 366 วันรวมต้น/ท้าย manager เรียกรายงานการเงินเจ้าของไม่ได้ทั้งหน้าจอและ API

## บัญชีผู้ใช้และดูแลข้อมูล

manager/owner ค้นหารายชื่อ ชื่อ อีเมล เบอร์โทรและบทบาทได้ เฉพาะ owner ลบบัญชีอื่นได้และลบตนเองไม่ได้ ไม่มีฟังก์ชันเปลี่ยนบทบาทในรอบนี้ อ่านวิธีสำรอง/กู้คืนและการหยุดระบบก่อน migration ใน [OPERATIONS.md](OPERATIONS.md) ลอง restore เป็นฐานใหม่ก่อนใช้ backup จริง และให้ผู้ใช้ทำ UAT ตาม [UAT.md](UAT.md)
