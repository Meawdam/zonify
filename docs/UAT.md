# UAT และการส่งมอบ Zonify

## รายการทดสอบเพิ่มเติม: ปฏิทินและการแจ้งเตือน

- [ ] ผู้ดูแลตั้งวันเปิดประจำ เพิ่มวันเปิด/ปิดพิเศษ และตรวจผังตามวันที่เลือก
- [ ] ปิดล็อกช่วงวันพร้อมเหตุผล ตรวจทั้งวันแรก/วันสุดท้าย และลบช่วงปิดเพื่อเปิดกลับ
- [ ] ทดลองปิดวันที่มีพักล็อก/รอชำระ/รอตรวจ/ยืนยันแล้ว ต้องไม่บันทึก เปิดรายการในแท็บใหม่แล้วแบบร่างปฏิทินยังอยู่
- [ ] สร้างร้าน → พักล็อก → ส่งสลิป → ผู้ดูแลปฏิเสธ → ผู้เช่าได้รับเหตุผลในกระดิ่ง → ส่งใหม่ → อนุมัติ → ร้านปรากฏตรงวันจอง
- [ ] ตรวจจำนวนงานค้างและลิงก์กรองรอตรวจสลิป รอชำระ รอคืนเงิน รวม reload และ Back/Forward
- [ ] กระดิ่งและประวัติแสดงเฉพาะบัญชีตนเอง ทำเครื่องหมายอ่านทีละรายการ/ทั้งหมดได้ เมื่อกลับเข้าแท็บข้อมูลอัปเดต
- [ ] รายการรอชำระที่ไม่เคยส่งสลิปได้รับคำเตือนช่วง 5 นาทีสุดท้าย หลังส่งสลิปหรือหมดเวลาคำเตือนเดิมไม่แสดง
- [ ] ตรวจบนมือถือและใช้คีย์บอร์ด บันทึกผล/ผู้ทดสอบตามแบบรับงานเดิมด้านล่าง

สถานะ: **เตรียมพร้อมสำหรับผู้ใช้ทดสอบ ยังไม่มีผู้ใช้ลงนามรับงาน** Automated QA ไม่ใช่ human UAT ไม่เปลี่ยนสถานะหรือวันงานจริงใน workbook เอกสารนี้ใช้บันทึกโดยผู้ใช้/ผู้ดูแลหลังทดลองบนเครื่อง

ผู้ทดสอบ: __________ วันที่: __________ รุ่น/commit: __________
สภาพแวดล้อม/เบราว์เซอร์: __________ ฐานข้อมูลทดสอบ: __________

ใช้ฐานข้อมูล UAT แยกและข้อมูลสมมติ ไม่ใช้เงินจริงจนเจ้าของตรวจตั้งค่าบัญชี/QR แล้ว บันทึก Expected/Actual และหลักฐานเมื่อไม่ผ่าน ข้อมูลตัวอย่างโฆษณา/ร้าน/สถานะรายวันไม่ใช่ผลดำเนินงานจริง

| รายการ | ผลที่คาดหวัง | ผลผู้ใช้ / หมายเหตุ |
| --- | --- | --- |
| สมัคร → login → refresh | สมัครเป็น customer, cookie คงอยู่, อีเมลซ้ำถูกปฏิเสธ | ยังไม่ทดสอบโดยผู้ใช้ |
| แก้ชื่อ/เบอร์โทร | บันทึกแล้ว refresh ยังเป็นค่าที่แก้ อีเมล/บทบาทอ่านอย่างเดียว | ยังไม่ทดสอบโดยผู้ใช้ |
| เปลี่ยนรหัสผ่านสองอุปกรณ์ | ทุก session เดิมใช้ไม่ได้ ต้อง login ใหม่ | ยังไม่ทดสอบโดยผู้ใช้ |
| Logout/หมดอายุ | เข้า profile/history ไม่ได้จน login ใหม่ | ยังไม่ทดสอบโดยผู้ใช้ |
| ค้นหาร้าน/ผัง/วัน/ตลาด | ผลและสถานะตรงกับข้อมูล; มือถือเลื่อนผังได้ | ยังไม่ทดสอบโดยผู้ใช้ |
| ลูกค้าสองคนจองล็อก/วันเดียวกัน | ผู้ชนะหนึ่งคน อีกคนได้ข้อขัดแย้ง; ไม่จองซ้ำ | ยังไม่ทดสอบโดยผู้ใช้ |
| พัก → ยืนยัน → รอชำระ | นับเวลาถูก ราคาเดิม รีเฟรชไม่ต่อเวลา หมดเวลาได้ล็อกคืน | ยังไม่ทดสอบโดยผู้ใช้ |
| QR ของบัญชีจริง | ชื่อ/บัญชี/ยอดในแอปธนาคารตรงกับที่ตั้งค่า | เจ้าของยังต้องตรวจจริง |
| ส่งสลิป/ปฏิเสธ/แก้/อนุมัติ | ภาพส่วนตัว เหตุผลชัด รอตรวจไม่ถือว่ารับเงิน | ยังไม่ทดสอบโดยผู้ใช้ |
| ยกเลิกรายการรับเงิน/คืนเงิน | ภาระคืนเงินเกิดและเลขอ้างอิงคืนถูกเก็บ; ไม่มีการโอนอัตโนมัติ | ยังไม่ทดสอบโดยผู้ใช้ |
| ผู้จัดการแก้ข้อมูล/ผัง | ค่าบันทึกจริง ไม่ชนตำแหน่ง ปิด/เปิดแสดงตรง | ยังไม่ทดสอบโดยผู้ใช้ |
| ข่าวเริ่ม/สิ้นสุด/ปิด | หน้าแรกแสดงเฉพาะช่วงวันและปลายทางที่เปิดแสดง | ยังไม่ทดสอบโดยผู้ใช้ |
| Dashboard/CSV | แยกวันที่จองกับวันที่รับ/คืน; ตัวกรองตรง; manager ไม่ได้รายงาน owner | ยังไม่ทดสอบโดยผู้ใช้ |
| Keyboard/มือถือ | ช่อง/ปุ่มเข้าได้ด้วย Tab/Enter ไม่มี page overflow | ยังไม่ทดสอบโดยผู้ใช้ |
| ปิด/เปิดระบบ | ข้อมูลเดิมยังอยู่ ไม่มี seed เขียนทับ | ยังไม่ทดสอบโดยผู้ใช้ |
| Backup → restore ฐานใหม่ | ข้อมูล/index/ภาพครบ ไม่มี session เดิม และต้นฉบับยังอยู่ | ยังไม่ทดสอบโดยผู้ใช้ |
